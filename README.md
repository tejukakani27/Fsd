# Full Stack Development (FSD)

A collection of full-stack web development projects, exercises, and applications built while learning modern frontend and backend technologies.

## 📂 Repository Structure

- **`FSD/`** — Main coursework and project directory containing web applications, server-side templates (EJS), JavaScript/React modules, and exercises.

## 🛠️ Technologies Covered

- **Frontend:** HTML5, CSS3, JavaScript, React, EJS (Embedded JavaScript Templates)
- **Backend:** Node.js, Express.js
- **Tools:** Git, GitHub, npm

## 🚀 How to Run a Project Locally

1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate into a specific project folder inside `FSD/`:
   ```bash
   cd Fsd/FSD/<project-folder-name>
   ```
3. Install dependencies and start the server:
   ```bash
   npm install
   npm start
   ```
